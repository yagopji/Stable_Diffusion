# 🎨 Stable Diffusion WebUI 사용 가이드

## 🚀 시작하기

### WebUI 실행

```bash
cd /home/01_AI그림생성_Stable_Diffusion/stable-diffusion-webui
./webui.sh
```

브라우저에서 `http://localhost:7860` 접속

---

## 📦 모델 선택하기

1. WebUI 상단에서 **Settings** 클릭
2. 왼쪽 메뉴에서 **Stable Diffusion** 클릭
3. **Stable Diffusion checkpoint** 드롭다운에서 **v1-5-pruned-emaonly.safetensors** 선택
4. **Apply settings** 클릭
5. 페이지 새로고침 (F5)

---

## 🎨 이미지 생성하기

### 기본 사용법

1. **텍스트 → 이미지** 탭 선택
2. **Prompt** 입력창에 원하는 이미지 설명 입력 (영어 권장)
3. **Negative Prompt**에 원하지 않는 것 입력 (선택사항)
4. **Generate** 버튼 클릭

### 프롬프트 예시

**풍경:**
```
majestic mountain landscape at sunrise, snow-capped peaks, golden hour lighting, cinematic, 4k, detailed
```

**동물:**
```
cute cat playing with yarn, kawaii style, colorful, high quality, detailed
```

**판타지:**
```
magical forest with glowing mushrooms, fairy tale style, vibrant colors, detailed
```

### 추천 설정

- **Sampling Steps**: 20-25
- **Width/Height**: 512x512
- **CFG Scale**: 7
- **Batch count**: 1
- **Batch size**: 1

## 🌐 한국어 UI 설정

1. **Settings** → **User interface** 클릭
2. **Localization (requires restart)** 드롭다운에서 **korean** 선택
3. **Apply settings** 클릭
4. 페이지 새로고침

---

## 💡 프롬프트 작성 팁

### 구조: `주제 + 스타일 + 품질`

**예시:**
- ✅ 좋은 예: `a red sports car, professional photography, high quality, detailed, 4k`
- ❌ 나쁜 예: `car`

### 유용한 키워드

**스타일:** `anime style`, `realistic`, `oil painting`, `watercolor`, `digital art`

**품질:** `high quality`, `detailed`, `4k`, `professional`, `sharp focus`

**분위기:** `cinematic lighting`, `golden hour`, `dramatic`, `peaceful`

### 한글 프롬프트 사용

한글 프롬프트는 자동 번역 기능이 있지만, **영어로 직접 작성하는 것이 더 좋은 결과**를 얻을 수 있습니다.

**추천 방법:** 한글 + 영어 키워드 혼합
```
아름다운 일몰 풍경, sunset over ocean, golden hour, cinematic, 4k, detailed
```

## 🔧 문제 해결

### 모델이 목록에 안 보여요
- WebUI 재시작
- Settings → Stable Diffusion → **Refresh** 클릭

### 이미지 생성이 너무 느려요
- Sampling Steps를 20으로 줄이기
- 이미지 크기를 512x512로 설정

### 에러가 발생해요
- 브라우저 새로고침 (F5)
- WebUI 재시작

### 한글 프롬프트 번역이 안 돼요
- 번역 기능은 선택사항입니다. 영어로 직접 작성하는 것을 권장합니다.
- 번역을 사용하려면: `pip install deep-translator` 설치 후 WebUI 재시작
